ASA Contracting Website

Files:
- index.html: main page
- style.css: complete responsive design
- script.js: Arabic/English translation, automatic language detection, mobile menu, animations
- assets/asa-logo.jpg: supplied ASA image

How to open:
Double-click index.html in a browser.

Language:
The site detects the browser language on first visit. Arabic browsers open Arabic automatically; other browsers open English. The AR/English button switches instantly and remembers the choice.

Before publishing:
Replace demo project placeholders with real project photos and update contact details. The contact form is visual/demo only until connected to an email service or backend.
